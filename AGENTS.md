# AGENTS.md

Instructions for non-Claude coding agents (OpenAI Codex / ChatGPT, etc.). Claude reads `.claude/CLAUDE.md`; the project rules there apply to you as well.

## Research pulse coordination

Claude also runs research-pulse scans on this repo, sometimes on a schedule. To avoid repeating each other's work:

- **Before any research-trends, business-insight, or "what's new" task**, read `research-pulse/digests/LEDGER.md` and follow its protocol: claim a topic, skip topics and sources already covered, write `research-pulse/digests/YYYY-MM-DD-openai.md`, and update the ledger when you finish.
- Your default lanes are listed in the ledger's "Topic lanes" table.
- To cross-check a Claude finding, mark it `verified` or `disputed` in the Run log instead of re-running the scan.
