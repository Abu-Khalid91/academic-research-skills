# AlSamadani Score (S_AlSamadani ∈ [0, 100])

A fail-closed governance and confidence-calibration layer for recursive multi-agent LLM decision support in the ICU/CVICU.

**Author:** Saud Khalid AlSamadani, MBBS, SB-ACCM. ORCID 0009-0008-1007-4616

> **Research software.** It is not a medical device, has not been validated on patient data, and is not for autonomous clinical use. Every performance figure is synthetic. Read `VERIFICATION_REPORT.md` before citing any number.

## Files

| File | Purpose |
|---|---|
| `alsamadani_score_calculator.py` | Core math (σ, CED_R, ρ_collapse, SPCE and ceiling, VOI), tiers, SSC 2026/KDIGO fallback, HMAC/PHI privacy layer, Monte Carlo and scaling benchmarks, MIMIC-IV v3.1/eICU-CRD loader |
| `test_alsamadani_score.py` | 38 unit tests |
| `alsamadani_score_jama_manuscript.tex` / `.pdf` | 10-page LuaLaTeX manuscript |
| `alsamadani_results.tex` / `.json` | Generated by the calculator; the manuscript `\input`s the `.tex` file |
| `VERIFICATION_REPORT.md` | What was verified, what was not, and what differs from the brief |

## Reproduce

```bash
pip install -r requirements.txt
python3 alsamadani_score_calculator.py           # demos, Monte Carlo, scaling; regenerates results files
python3 -m pytest -q test_alsamadani_score.py
lualatex -interaction=nonstopmode -halt-on-error alsamadani_score_jama_manuscript.tex   # run twice
```

Production pseudonymization requires the `ALSAMADANI_HMAC_SALT` environment variable (at least 16 bytes, kept secret). Without it, `Pseudonymizer()` refuses to run.
